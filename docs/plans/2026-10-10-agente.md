# Etapa 6 (agente de IA): plano de implementação

> **Para quem executa:** use superpowers:executing-plans (ou subagent-driven-development), tarefa por tarefa. Os passos usam caixas `- [ ]`.

**Objetivo:** agente que transforma perguntas em português em SQL sobre as marts, executa num usuário somente leitura e responde com número, tabela, SQL e gráfico, publicado no Streamlit Community Cloud.

**Arquitetura:** pacote `agente/` com funções pequenas e testáveis (guarda de SQL, checagem de números, regra de gráfico, cliente de modelo com reserva, fluxo), uma interface Streamlit em `agente/app.py` e o usuário `agente_leitura` criado por uma função reaproveitada no Neon, no `publicar_marts.py` e no CI.

**Stack:** Python 3.11, `openai` (cliente no formato da API da OpenAI, apontado para Gemini e Groq), `sqlglot`, `psycopg2`, `pandas`, Streamlit, pytest.

**Especificação:** [docs/specs/2026-10-10-agente-design.md](../specs/2026-10-10-agente-design.md)

**Ajustes em relação à spec:**
- O app fica em `agente/app.py`, e não na raiz. O Streamlit Cloud procura as dependências primeiro na pasta do app, então `agente/requirements.txt` evita instalar dbt e scikit-learn no deploy.
- O usuário `agente_leitura` é criado por `agente/permissoes.py` (com o atalho `scripts/criar_usuario_agente.py`), e não por um `.sql`: as permissões são tabela a tabela, a senha vem do ambiente, e a mesma função serve ao Neon, ao `publicar_marts.py` e ao teste do CI.

## Restrições globais

- Modelo gratuito: Gemini Flash (camada gratuita) e Groq `llama-3.3-70b-versatile` (camada gratuita). Ids de modelo e URLs vêm de variáveis de ambiente, com valor padrão em `agente/config.py`.
- URLs no formato OpenAI: Gemini `https://generativelanguage.googleapis.com/v1beta/openai/`, Groq `https://api.groq.com/openai/v1`.
- Tabelas permitidas: `fato_pedidos`, `fato_itens_pedido`, `dim_clientes`, `dim_produtos`, `dim_vendedores`, `dim_tempo`, `dim_geolocalizacao`, `previsao_atraso` (schema `marts`).
- Limites: `LIMIT 1000`, `statement_timeout` 5 s, pergunta até 300 caracteres, 20 perguntas por sessão, 3 turnos de histórico, 50 linhas para a resposta escrita, 2 tentativas de SQL.
- Segredo nunca no Git: chaves e senha no `.env` (local) e nos *secrets* do Streamlit. Varredura de `npg_`, `AIza`, `gsk_` antes de cada commit que toca configuração.
- Sem travessão; `.md` com acento; código e comentários sem acento; textos de tela em português com acento.
- Comandos Python do projeto: `.venv\Scripts\python.exe` (o `py` também serve para os testes).

## Foco de revisão

1. Resultado vazio (0 linhas): a resposta diz que não há registros, sem inventar número. Teste na Task 5.
2. Valores `Decimal`, `None` e datas vindos do psycopg2: checagem de números, gráfico e tabela não quebram. Testes nas Tasks 3 e 5.
3. Cota esgotada depois do SQL executado (chamada 2 falha): o app mostra tabela e SQL, sem frase. Teste na Task 5.
4. Pergunta de continuação com histórico longo: só os 3 últimos turnos vão ao prompt. Teste na Task 5.
5. Banco do Neon acordando (primeira conexão lenta ou recusada): mensagem amigável, sem traceback na tela. Teste na Task 6.

### Task 2: guarda de SQL

**Arquivos:**
- Criar: `agente/guarda_sql.py`, `tests/test_agente_guarda.py`

**Interfaces:**
- Consome: `TABELAS_PERMITIDAS`, `SCHEMA`, `LIMITE_LINHAS`.
- Produz: `class SQLRecusado(Exception)` com atributo `motivo: str` (texto de tela em português); `validar(sql: str) -> str` (devolve o SQL pronto para executar, com `LIMIT`).

- [ ] **Passo 1: testes.** Passam e voltam com `LIMIT`:
  - `SELECT count(*) FROM fato_pedidos` → contém `LIMIT 1000`;
  - `WITH m AS (SELECT ...) SELECT ...` sobre tabelas permitidas;
  - `SELECT ... LIMIT 10` mantém 10; `LIMIT 5000` vira 1000;
  - schema explícito `marts.dim_tempo` e alias de CTE com nome qualquer.

  Recusados (`pytest.raises(SQLRecusado)`):
  - `SELECT 1; DROP TABLE marts.fato_pedidos`;
  - `DELETE FROM fato_pedidos`, `UPDATE ...`, `INSERT ...`, `DROP ...`, `CREATE TABLE ...`;
  - `WITH x AS (DELETE FROM fato_pedidos RETURNING *) SELECT * FROM x`;
  - `SELECT * INTO marts.copia FROM fato_pedidos`;
  - `SELECT * FROM fato_pedidos FOR UPDATE`;
  - `SELECT * FROM obt_pedidos`, `SELECT * FROM seguranca_bi`, `SELECT * FROM raw.orders`, `SELECT * FROM meta.execucoes_dbt`, `SELECT * FROM pg_catalog.pg_user`, `SELECT * FROM information_schema.tables`;
  - `SELECT pg_sleep(10)`, `SELECT set_config('statement_timeout','0',false)`, `SELECT * FROM dblink('x','y')`, `SELECT pg_read_file('/etc/passwd')`;
  - texto vazio e texto que não é SQL.
- [ ] **Passo 2: rodar** `py -m pytest tests/test_agente_guarda.py -q` → falha.
- [ ] **Passo 3: implementar** com `sqlglot.parse(sql, read="postgres")`: exatamente um comando; raiz `exp.Select` ou `exp.Union`; nenhum nó `Insert`, `Update`, `Delete`, `Drop`, `Create`, `Alter`, `Command`, `Into`, `Lock` em lugar nenhum da árvore; toda `exp.Table` que não é nome de CTE precisa ter schema vazio ou `marts` e nome na lista; funções (`exp.Anonymous` e nomes de função) contra a lista negada `pg_sleep`, `pg_sleep_for`, `pg_sleep_until`, `set_config`, `dblink`, `pg_read_file`, `pg_read_binary_file`, `pg_ls_dir`, `lo_import`, `lo_export`, `pg_terminate_backend`, `pg_cancel_backend`, `current_setting`; `LIMIT` acrescentado ou reduzido no comando externo. Devolver `expressao.sql(dialect="postgres")`.
- [ ] **Passo 4: rodar** → todos passam.
- [ ] **Passo 5: commit** `feat(agente): guarda de SQL com lista permitida`.

### Task 3: checagem de números e regra de gráfico

**Arquivos:**
- Criar: `agente/numeros.py`, `agente/grafico.py`, `tests/test_agente_numeros.py`, `tests/test_agente_grafico.py`

**Interfaces:**
- Produz: `extrair_numeros(texto: str) -> list[float]`; `confere(texto: str, valores: list, extras: list = ()) -> bool` (`valores` são as células do resultado, podendo ter `Decimal`, `int`, `float`, `None`, `date`, `str`; `extras` são números da pergunta e do SQL).
- Produz: `escolher_grafico(df: pandas.DataFrame, pedido: bool, palpite: str | None) -> str | None` (devolve `"linha"`, `"barras"` ou `None`).

- [ ] **Passo 1: testes de números.**
  - `extrair_numeros("R$ 1.565.470,97")` → `[1565470.97]`; `"15,79 mi"` → `[15790000.0]`; `"R$ 2,3 milhões"` → `[2300000.0]`; `"8 mil"` → `[8000.0]`; `"93,2%"` → `[93.2]`; `"2018-03"` e `"mar/2018"` não geram número.
  - `confere("A receita foi de R$ 15,79 mi.", [Decimal("15786203.57")])` → `True`; `confere("93,2% no prazo", [0.93226])` → `True`; `confere("RJ teve 659 atrasos a mais", [Decimal("658.65")])` → `True`; `confere("SP lidera com 41 mil pedidos", [Decimal("40501")])` → `False`; `confere("Foram 8.468 pedidos", [8467])` → `False`; `confere("Em 2018 foram 3 UFs", [12], extras=[2018, 3])` → `True`; `confere("Nenhum registro encontrado.", [])` → `True`; `None` e `date` em `valores` são ignorados.
  - Tolerância: casa se `abs(n - v) <= max(0.005 * abs(v), 0.01)`; percentual testa `n` e `n / 100`; número com abreviação (`mi`, `mil`, `bi`) testa também o arredondamento da mesma ordem de grandeza.
- [ ] **Passo 2: testes de gráfico.**
  - 20 linhas com `ano_mes` + número → `"linha"`; colunas `data` (date) + número → `"linha"`;
  - 5 UFs + número → `"barras"`; 40 categorias + número, sem pedido → `None`; com `pedido=True` → `"barras"`;
  - 1 linha → `None`; só colunas de texto → `None`; série mensal com `palpite="barras"` → `"barras"`;
  - números como `Decimal` contam como numéricos.
- [ ] **Passo 3: rodar** → falham.
- [ ] **Passo 4: implementar** os dois módulos (coluna de tempo: nome em `ano_mes`, `mes`, `data`, `ano`, `trimestre` ou tipo data).
- [ ] **Passo 5: rodar** → passam.
- [ ] **Passo 6: commit** `feat(agente): checagem anti-invencao de numeros e regra de grafico`.

**Interfaces:**
- Consome: `validar`, `SQLRecusado` (Task 2); `confere`, `escolher_grafico` (Task 3); `agente/esquema_marts.md` (Task 4).
- Produz: `Provedor(nome: str, base_url: str, modelo: str, chave: str)`; `provedores_do_ambiente() -> list[Provedor]` (Gemini primeiro, Groq depois, pula quem não tiver chave); `class CotaEsgotada(Exception)`; `ClienteLLM(provedores, fabrica=openai.OpenAI)` com `completar(mensagens: list[dict], json: bool = False) -> str` (no `RateLimitError` passa para o próximo; se todos falharem, `CotaEsgotada`).
- Produz: `abrir_conexao() -> connection` (variáveis `AGENTE_DB_*`, `sslmode=require` fora do localhost); `class ErroBanco(Exception)`; `executar(conexao, sql: str) -> tuple[list[str], list[tuple]]`.
- Produz: `Turno(pergunta: str, sql: str)`; `Resposta(tipo: str, texto: str, sql: str | None, colunas: list[str], linhas: list[tuple], grafico: str | None, confirmada: bool)` com `tipo` em `"ok"`, `"vazio"`, `"fora_do_escopo"`, `"recusado"`, `"erro"`, `"cota"`; `responder(pergunta: str, historico: list[Turno], llm: ClienteLLM, executar: Callable[[str], tuple[list[str], list[tuple]]], esquema: str) -> Resposta`.

- [ ] **Passo 1: testes do cliente** (`fabrica` falsa): o primeiro provedor responde → usa ele; o primeiro levanta `RateLimitError` → usa o segundo; os dois levantam → `CotaEsgotada`; `json=True` pede `response_format={"type": "json_object"}`.
- [ ] **Passo 2: testes do fluxo** com `llm` e `executar` falsos:
  - caminho feliz: JSON `{"sql": "SELECT count(*) AS pedidos FROM fato_pedidos", "grafico": null}`, resultado `[(99441,)]`, resposta "Foram 99.441 pedidos." → `tipo="ok"`, `confirmada=True`, SQL com `LIMIT`;
  - resposta com número inventado ("Foram 120 mil pedidos") → `confirmada=False`, `texto` vira o aviso "Resposta automática não confirmada; confira a tabela.";
  - primeiro SQL dá `ErroBanco`, segundo funciona → segunda chamada de SQL recebe a mensagem de erro no prompt; `tipo="ok"`;
  - dois erros seguidos → `tipo="erro"`, com o último SQL;
  - `{"fora_do_escopo": "a base não tem custo dos produtos"}` → `tipo="fora_do_escopo"`, nenhuma execução;
  - SQL recusado pela guarda → `tipo="recusado"`, `executar` nunca chamado;
  - resultado vazio → `tipo="vazio"`, texto "Nenhum registro encontrado para essa pergunta.", sem chamada 2;
  - `CotaEsgotada` na chamada 2 → `tipo="ok"`, `confirmada=False`, tabela e SQL presentes;
  - `CotaEsgotada` na chamada 1 → `tipo="cota"`;
  - histórico com 5 turnos → o prompt contém só os 3 últimos;
  - resultado com `Decimal`, `None` e `date` → não quebra.
- [ ] **Passo 3: rodar** → falham.
- [ ] **Passo 4: implementar.** `prompts.py` guarda os textos: sistema do SQL (regras da seção 4 da spec, saída só em JSON), 6 exemplos de pergunta e SQL diferentes das perguntas da Task 7, sistema da resposta ("use só os números do resultado; 1 a 3 frases; formato brasileiro"). A chamada 2 recebe as linhas como CSV (até `LINHAS_NA_RESPOSTA`). `executar` abre transação, `SET TRANSACTION READ ONLY`, `SET LOCAL statement_timeout`, e converte erro do psycopg2 em `ErroBanco` com a primeira linha da mensagem.
