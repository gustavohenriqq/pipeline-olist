# Componentes de terceiros

## HTML Content (Standalone) 2.0.0

- **O que é:** visual do Power BI que desenha HTML e CSS gerados por medidas DAX
  (Etapa 8).
- **Onde está no projeto:** `dashboards/powerbi/Olist.Report/CustomVisuals/STANDALONEhtmlContent443BE3AD55E043BF878BED274D3A6855/`.
  O Power BI guarda o visual importado dentro do relatório (PBIP); sem essa pasta,
  quem clona o repositório abre o relatório com o visual faltando.
- **Origem:** https://github.com/dm-p/powerbi-visuals-html-content/releases/tag/2.0.0.0
  (pacote `HTML-Content-Standalone.2.0.0.pbiviz`, a edição feita para importar de
  arquivo, sem a loja).
